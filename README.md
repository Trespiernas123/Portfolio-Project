# Keys to the Universe

## Overview

Keys to the Universe is my personal portfolio project created for the Nucamp Web Fundamentals course.

The website presents my personal journey, education, professional experience, interests, and goals as I continue developing my skills in technology and web development.

The project is inspired by curiosity, learning, personal growth, and the idea of discovering new opportunities. The concept of "Keys to the Universe" represents the different experiences and skills that can open doors to the future.

## Features

- Responsive professional portfolio website.
- English and Spanish language options.
- Interactive navigation.
- Personal introduction and background.
- Education and professional experience.
- Technology and engineering interests.
- Interactive quiz with feedback messages.
- Information and inspiration related to Nikola Tesla and the numbers 3, 6, and 9.
- Custom styling with CSS and SCSS.
- JavaScript functionality for interactive elements.
- Bootstrap components and responsive design.
